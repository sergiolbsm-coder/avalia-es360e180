# Avaliação 360° e 180° · Instituto da Liderança

| | Arquivo |
|---|---|
| Questionário (link do convite `?t=CÓDIGO`) | `360.html` |
| Painel do Instituto (exige chave de administração) | `360-admin.html` |
| Portal da empresa (só participação) | `360-portal.html` |
| Backend (Apps Script) | `APPS_SCRIPT_360.gs` |
| Configuração do modelo | `360-config.json` |

Metodologia, regras de anonimato e publicação: [docs/metodologia-360-idl.md](docs/metodologia-360-idl.md).

A URL do backend fica em `360-api.js`. Para atualizar o script: Implantar → Gerenciar implantações → lápis → Nova versão (nunca "Nova implantação").
